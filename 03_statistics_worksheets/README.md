# Statistical Analysis Worksheets

Weekly worksheets from the statistics strand of *Data Science in the Life
Sciences*, Freie Universität Berlin — group 6.

The sequence runs from descriptive statistics and distributions through
hypothesis testing and multiple testing correction, into linear and multiple
regression. Most are written in R Markdown, which keeps the analysis, the output
and the interpretation in one document.
